# Original assignment source workbooks

These files are the original inputs for Assignment 1. Keep them unchanged,
including layout, labels, formulas, and precision. Read from them; write generated
reports elsewhere. They are not completed assignment reports.

| Workbook | Purpose |
| --- | --- |
| [Automation Build Challenge - NA.xlsx](./Automation%20Build%20Challenge%20-%20NA.xlsx) | North American monthly expense information. The workbook includes presentation material around the accounting data. Inspect it before deciding how to read it. |
| [Automation Build Challenge - SA.xlsx](./Automation%20Build%20Challenge%20-%20SA.xlsx) | South American monthly expense information. Inspect its structure and values rather than assuming every visible cell is an accounting record. |
| [Automation Build Challenge - Managers.xlsx](./Automation%20Build%20Challenge%20-%20Managers.xlsx) | Country, manager, and team-size reference information across North America, Europe, and South America sheets. Check the information needed for your accounting problem and report unused references separately from unmatched expenses. |

Workbooks may use inconsistent text formatting or numeric precision. Ask your
assistant to inspect and explain observations without rewriting these sources.
Do not assume a currency conversion, missing-value replacement, or rounding rule
that the assignment has not specified. Resolve material accounting questions with
the instructor. No original Alteryx output or completed solution is supplied in
this folder. See the [assignment](../assignment.md) for required report fields.
